**Table 12. Architecture ablation — the multi-agent pipeline vs. a single-agent ReAct loop, same model, same tools (T3.3, reframed).**
The naive baseline (`eval/baselines/react.py`) is one `deepseek-v4-flash` — the *same* base model IEQ-Ops uses — in a hand-written thought→action→observation loop over the *same* MCP tools (`read_sensors`, `retrieve_standards` → the identical RAG retrieve, `set_ventilation`). What it lacks is the architecture: no planner DAG, no domain-specialist isolation, no Agentic-RAG self-reflection, no critic gate. Both arms run on the same anomaly; both diagnoses are judged by the *same* CriticAgent (would this diagnosis be allowed to act?). So a system − baseline gap is attributable to the architecture, not the model. Per-domain, n=5 samples/task.

**What the gap actually measures — a robustness finding, stated at the height the evidence permits, not a "reasoning-superiority" claim.** The separation on thermal and lighting is real and domain-dependent: where the base model can one-shot the problem (CO2), the architecture adds nothing (gap 0); where the task needs retrieval + multiple steps + a structured output, the single-agent loop is markedly less reliable. But the mechanism of the gap is narrower than "multi-agent reasons better," and must be reported as such:
- **The baseline's failures are predominantly "no valid `finish` within its 6-step budget"** (thermal: both 2 failures are no-finish; acoustic: 2 of 3). A hand-rolled ReAct loop that must emit strict JSON every turn is fragile at converging inside a step cap; the structured pipeline always emits a typed diagnosis. So the honest claim is **output reliability** — *the structured pipeline reliably produces a critic-passable diagnosis where the unstructured loop often fails to converge within budget* — not that the pipeline out-reasons the loop on the ones the loop does finish.
- **Neither arm has a thermal / lighting / acoustic actuator** (only `set_ventilation` exists; the other three domains are Phase 5). Scoring is therefore the CriticAgent's approve/reject on the *diagnosis*, not whether the anomaly was physically fixed. This table is about producing a trustworthy diagnosis under the same tools, not about closed-loop resolution (that is Table 17, airquality only).
- **The system arm is NOT memory-free.** Its planner runs live episodic recall (`planner.run → retrieve_similar`) against the production Qdrant collection, so on these novel e2e anomalies it carries whatever the nearest (irrelevant) past case injects — the exact contamination Table 16 quantifies at 100%. Memory is thus a *live confound* in this comparison, not an absent variable; the gap conflates architecture with whatever recall did on the day. A fully clean architecture-only isolation would disable recall in the system arm — logged as a refinement, not claimed as already done.

**acoustic is reported but drawn no conclusion from: at n=5 it is 1/5 vs 2/5, a single-sample flip well inside sampling noise** (and 2 of the baseline's 5 runs did not finish at all). Reading a "−20 pp decomposition penalty" into one sample would be the same overclaim this dissertation is at pains to avoid elsewhere; the honest statement is "no separation detectable at this n."

**The secondary lesson (why the earlier "+10 pp over ReAct" headline was abandoned).** Earlier runs (`compare-*.json`) chased a single macro-gap number and it proved unstable (25.0 → 10.0 → 6.7 → 0.0 pp across four runs), carried by whichever domain happened to separate that day, and collapsing to zero on deliberately *harder* self-contradiction traps — a strong base model defeats "trick-the-baseline" task design. That instability is itself informative: measurable separation comes only from capabilities the baseline is *structurally* unable to reproduce (multi-step planning, retrieval reflection, cross-incident memory), which is why the dissertation's load-bearing evidence rests on the grounding ablation (Table 4) and the memory ablation (Tables 5/15/16), and treats this architecture comparison as a bounded robustness result, not a benchmark-supremacy claim.
